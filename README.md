========================================================================
DiffCraft Studio v2.2.0 (Portable Standalone Edition)
Zero Installation - 100% Client-Side - 100% Offline \& Corporate Policy Safe
===

HOW TO RUN:

1. Double-click on "index.html" to open DiffCraft Studio in your web browser
(Google Chrome, Microsoft Edge, Firefox, Brave, Safari, etc.)
2. No installation, no Node.js, and no internet connection required!
All files and comparisons remain 100% private in your browser memory.

FEATURES:

* Side-by-side \& unified text diff view with line numbers
* Character \& word-level intra-line difference highlighting
* Word Wrap mode (toggle on/off for long lines with synchronized row heights)
* Bilingual UI: Instant Thai (TH) and English (EN) language switcher
* Interactive merge: Copy diff blocks Left -> Right and Right -> Left
* Full text search (Ctrl + F), JSON Formatter, and HTML Diff Report export
* Undo / Redo (Ctrl+Z / Ctrl+Y) for edits, merges, and file loads
* File encoding selection: Auto, UTF-8, TIS-620 / Windows-874 (Thai), UTF-16 LE
* Save back to the original file (Ctrl+S) in Chromium-based browsers
* Keyboard shortcuts: F7 / Alt+Down (Next Diff), Shift+F7 / Alt+Up (Prev Diff)
