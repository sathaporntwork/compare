v2.2.0 — Beyond Compare Mode, Undo, Encoding & Save 2026-10-16
  • Beyond Compare Line Details & Red Diff: เพิ่มแถบ Line Details ด้านล่างสำหรับตรวจสอบคู่บรรทัดแบบขยายเจาะลึกระดับตัวอักษร พร้อมโทนสีแดง Beyond Compare แท้ทั้งสองฝั่ง (ไม่ใช้สีเขียวแบบ Git) และนำเส้นขีดฆ่าตรงกลางออกเพื่อความสบายตา
  • Undo / Redo: ย้อนกลับและทำซ้ำการแก้ไข, merge, การวาง และการเปิดไฟล์ ด้วยปุ่มหรือ Ctrl + Z / Ctrl + Y
  • Encoding Selection: เลือกการอ่านไฟล์เป็น Auto / UTF-8 / TIS-620 (Windows-874) / UTF-16 LE รองรับไฟล์ภาษาไทยรุ่นเก่า
  • Save to File: Ctrl + S บันทึกกลับไฟล์เดิม คงค่า CRLF และ BOM (ใช้ได้เต็มรูปแบบบน Chromium; เบราว์เซอร์อื่นจะดาวน์โหลดไฟล์แทน)
  • Thai Word Diff: ไฮไลต์ความต่างระดับคำภาษาไทยได้ถูกต้อง
  • Fixes: Unified Patch ใช้เลขบรรทัดจริง, escape ชื่อไฟล์ในรายงาน HTML, แก้การแก้ไขสองฝั่งชนกันตอน debounce, จำกัดจำนวน Session และรองรับไฟล์ที่มีบรรทัดยาวมาก
v2.1.0 — Standalone & Enterprise Release 2026-10-15
  • Enterprise Custom Dialogs & Toast: ยกเลิก Dialog ดั้งเดิมของเบราว์เซอร์ทั้งหมด เปลี่ยนเป็น Custom Modal UI ของระบบเอง 100% พร้อม Toast Notifications
  • Smart Paste & Drag-Drop: กด Ctrl + V วางข้อความได้ทันทีจากทุกที่, เพิ่มปุ่มวางเฉพาะฝั่ง, การ์ด Empty State และรองรับการ Drag & Drop ข้อความดิบ
  • Standalone Release.zip: รันแบบพกพาโดยไม่ต้องลงโปรแกรม ดับเบิลคลิกเปิดไฟล์ index.html ใช้งานได้ทันที 100% Offline
  • Text Wrap Mode (ตัดคำ): เพิ่มโหมดตัดคำขึ้นบรรทัดใหม่เมื่อข้อความยาว พร้อมล็อกระดับความสูงแถวซ้าย-ขวาให้ตรงกันเสมอ
  • Bilingual UI (TH/EN): สลับภาษาไทยและอังกฤษได้ทันที จดจำภาษาอัตโนมัติ
  • Rebranding to DiffCraft Studio: เปลี่ยนชื่อระบบเพื่อความปลอดภัยและมาตรฐานเครื่องหมายการค้า
v2.0.0 — Production TypeScript & Multi-User Isolation 2026-10-15
  • TypeScript Migration: พัฒนาระบบใหม่ด้วย TypeScript 100% ทั้งฝั่ง Client และ Server
  • Strict Multi-User Isolation: แยก Session ใน Memory ไม่มีการแชร์ข้อมูลข้ามผู้ใช้
  • In-Memory Auto-Reaper & Shredder: ลบ Session อัตโนมัติเมื่อไม่มีการใช้งาน และปุ่มล้าง Memory ทันที
  • Docker & Compose Ready: รองรับการ Deploy ระดับองค์กรพร้อมจำกัด Resource
v1.0.0 — Initial Release 2026-10-15
  • Side-by-side diff view พร้อมเลขบรรทัด และ Synchronized Scrolling
  • Intra-line word & character difference highlights
  • Minimap overview gutter, bidirectional merge, JSON beautifier และ HTML Diff Report export
